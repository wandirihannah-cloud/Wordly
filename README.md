
# Wordly Dictionary

Your world of words.

## About the Project

Wordly is a single-page dictionary application that allows users to search for English words and view their definitions, pronunciation, and synonyms.

## Features

- Search for English words
- Display word definitions
- Show pronunciation when available
- Display synonyms when available
- Handle words that cannot be found
- Interactive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Free Dictionary API

## Project Structure

```text
wordly/

```

## How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter an English word in the search box.
5. Click the Search button to view the results.

An internet connection is required to retrieve dictionary data.

## API

This project uses the Free Dictionary API.

https://api.dictionaryapi.dev/api/v2/entries/en/

## Learning Objectives

This project demonstrates the use of semantic HTML, CSS styling, JavaScript event listeners, asynchronous programming, Fetch API requests, and DOM manipulation.
